# Task 2 - Data Retrieval & Sorting Dashboard

## Description

A web-based dashboard for retrieving, displaying, sorting, and filtering student records stored in a Supabase database.

## Objectives

This task demonstrates:

- Retrieving student records from a database
- Displaying student records in a dashboard
- Sorting records by name
- Sorting records by date
- Filtering records by department
- Counting students per department

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase

## Features

### Student Records

Displays:

- Name
- Email
- Date of Birth
- Department
- Phone Number

### Sorting

- Name A → Z
- Name Z → A
- Date Oldest → Newest
- Date Newest → Oldest

### Filtering

Students can be filtered by department.

### Department Count

Displays the number of students in each department.
