# Task 3 - Login System with Validation

## Description

Develop a Login Page that validates user inputs using JavaScript, checks credentials from a database, and displays error messages dynamically.

## Features

- Login page
- Email and password fields
- JavaScript input validation
- Database credential verification
- Dynamic error messages
- Successful login handling
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase

## Task Requirements

1. Develop a Login Page
2. Validate inputs using JavaScript
3. Check credentials from the database
4. Show error messages dynamically

## Real-Time Usage

Authentication systems are commonly used in:

- Student portals
- College management systems
- Banking applications
- E-commerce websites
- Social media applications
- Employee portals
