SQL CONCEPTS

Concepts Used

Task 04 demonstrates how relational database queries are used in an order management system.

JOIN Customers → Orders → Order Items → Products
SUBQUERY Find the highest-value order
GROUP BY Count orders for each customer
ORDER BY Sort orders by date and amount
FOREIGN KEY Connect customers, orders and products
REST API Node.js and Express provide order data
