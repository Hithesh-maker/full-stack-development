DATABASE CONCEPTS

SQL Concepts Used

TRANSACTION Groups multiple database operations into one atomic operation.
COMMIT Permanently saves successful payment changes to MySQL.
ROLLBACK Reverses database changes when a payment fails.
UPDATE Updates user and merchant account balances.
INSERT Stores successful payment information in the transaction history.
NODE.JS + EXPRESS Provides the backend API connecting the frontend to MySQL.
