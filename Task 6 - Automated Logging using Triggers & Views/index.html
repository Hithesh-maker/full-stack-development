DATABASE AUTOMATION

How Automated Logging Works

Database changes are captured automatically without requiring manual logging from the application.

01

INSERT / UPDATE

A student record is created or modified in the database.

02

Trigger Fires

MySQL automatically executes the appropriate trigger.

03

Audit Log Created

The operation, table name, record ID and description are stored.

04

Daily Report

The SQL view summarizes database activity by date and operation.

SQL CONCEPTS

Concepts Used

TRIGGER Automatically executes after INSERT or UPDATE
AUDIT LOG Stores database activity and change history
OLD Represents previous values during an UPDATE
NEW Represents the latest values during INSERT or UPDATE
VIEW Virtual table used for the daily activity report
GROUP BY Groups operations by date and operation type
